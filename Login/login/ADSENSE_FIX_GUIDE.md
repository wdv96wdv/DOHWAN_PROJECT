# Google AdSense 정책 위반 해결 가이드

## ✅ 수정 완료 사항

### 1. Privacy 페이지 개선
- ✅ Google AdSense 쿠키 정책 추가
- ✅ Google 광고 설정 및 개인정보 보호 링크 추가
- ✅ 쿠키 사용 목적 명시

### 2. 팝업 광고 최적화
- ✅ 팝업 z-index를 AdSense 광고(z-index: 9999)보다 낮게 조정 (9998)
- ✅ AdSense 광고와의 충돌 방지

### 3. AdSense 광고 컴포넌트 생성
- ✅ 재사용 가능한 AdSense 컴포넌트 생성 (`src/components/Ad/AdSense.jsx`)

## 📋 추가로 확인해야 할 사항

### 1. 실제 광고 배치
현재 AdSense 스크립트는 있지만 실제 광고 블록이 표시되지 않을 수 있습니다.

**해결 방법:**
```jsx
// 예: Home.jsx 또는 다른 페이지에 광고 추가
import AdSense from '../components/Ad/AdSense';

// 섹션 사이에 광고 배치
<AdSense 
  adFormat="auto"
  fullWidthResponsive={true}
  style={{ margin: '20px 0' }}
/>
```

**권장 광고 배치 위치:**
- 메인 콘텐츠 상단 (Hero Section 아래)
- 콘텐츠 섹션 사이 (2-3개 섹션마다)
- 하단 Footer 위

### 2. AdSense 정책 준수 체크리스트

- ✅ **콘텐츠 품질**: 고유하고 유용한 콘텐츠 제공
- ✅ **개인정보 보호 정책**: AdSense 쿠키 정책 포함 완료
- ✅ **광고 클릭 유도 금지**: "광고를 클릭해주세요" 같은 메시지 없음
- ✅ **팝업 광고 충돌**: z-index 조정 완료
- ⚠️ **광고 배치**: 실제 광고 블록 표시 필요
- ⚠️ **사이트 트래픽**: 충분한 방문자 확보 필요

### 3. Google AdSense 정책 주요 위반 사항 (피해야 할 것)

1. ❌ 광고 클릭 유도 메시지
   - "광고를 클릭해주세요"
   - "이 버튼을 눌러주세요"
   
2. ❌ 광고 모양의 다른 요소
   - 광고처럼 보이는 버튼이나 링크
   - "광고"라고 명시하지 않은 스폰서 콘텐츠
   
3. ❌ 팝업/오버레이로 콘텐츠 가리기
   - 사용자가 콘텐츠를 볼 수 없도록 하는 팝업
   
4. ❌ 자동 리디렉션
   - 광고 클릭 없이도 페이지 이동
   
5. ❌ 허위/오해의 소지가 있는 콘텐츠
   - "무료"라고 했지만 실제로는 유료
   - 허위 의료/건강 정보

### 4. 추가 권장 사항

1. **콘텐츠 최소 요구사항**
   - 최소 5-10개의 유용한 페이지
   - 정기적으로 업데이트되는 콘텐츠
   - 명확한 네비게이션 구조

2. **모바일 최적화**
   - 반응형 디자인 적용 (이미 적용됨)
   - 모바일에서도 광고가 제대로 표시되는지 확인

3. **사이트 속도**
   - 페이지 로딩 속도 최적화
   - AdSense 스크립트는 이미 `async` 속성으로 로드됨

4. **이의 신청 방법**
   - AdSense 계정에서 "정책 위반" 알림 확인
   - 위반 사항 수정 후 재검토 요청
   - 수정 사항을 명확히 문서화하여 제출
